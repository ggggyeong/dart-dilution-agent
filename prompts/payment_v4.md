# 역할

공시에서 회사가 신주/사채 대금을 무엇으로 받는지 분류한다.

# 입력 설명

입력은 공시 1건에서 판단에 필요한 칸만 골라 "칸 이름: 값"으로 적은 글이다. 묶음마다 [대괄호 제목]이 붙어 있다.

- [기본] 공시 제목, 유상증자면 증자 방식(CI_MTH), CB면 납입 방법(PYM_DET).
- [납입 자산] 유상증자: 현물출자 여부(PIN_EXT_YN) · 현물출자 가액(PIN_VAL) · 현물출자로 발행하는 주식 수(PAY_EXP_CNT). CB: 납입자산 부속표(TBL_PYM) 전부 — 납입자산 종류(PYM_KND) · 상세 내역(PYM_DTL) · 평가 방법(PYM_AUD).
- [돈의 용도] 자금 용도 6칸(시설 · 영업양수 · 운영 · 채무상환 · 타법인 증권 취득 · 기타), 제3자배정 목적(OBJ), 타법인 취득 부속표 전부.
- [받는 사람] 대상자 표. 유상증자: 대상자(PART) · 관계(RLT) · 선정경위(SLT_JDG) · 증자결정 전후 6월 이내 거래내역(MNTH) · 배정주식수(ALL_CNT). CB: 대상자(ISSU_NM) · 관계(RLT) · 선정경위(ISSU_SLT) · 거래내역(ISSU_HST) · 발행금액(ISSU_AMT).
- [글] 현금이 아닐 수 있다는 신호가 걸린 문단과 그 바로 앞뒤 문단, 각주 "주1)" 문단.

# 판정 절차

질문 3개를 순서대로 답한다. 앞 질문 답이 정해지면 다음으로 간다.

- Q1. 현금 말고 다른 것으로 납입하는 내용이 있는가? 없으면 → 현금, 끝.
- Q2. 그 다른 것이 원래 있던 빚인가, 받는 자산인가, 둘 다 특정되지 않았는가? 빚 → 빚→주식 / 자산 → 현물 / 특정 안 됨 → 불명.
  빚이나 받는 자산이 글에 특정돼 있지 않으면 추측하지 말고 불명.
- Q3. 현금 납입도 같이 있는가? 있으면 → 섞임.

# 값 정의

| 공시에 적힌 것 | 값 |
|---|---|
| 회사가 **원래 지고 있던 빚**이 특정됨 (차입금 · 사채 · 미지급금 · 회생채권 · 대여금 · 합의금 등 채권, 금액·차입 시점·채권자 중 하나 이상) | 빚→주식 |
| **받는 자산**이 특정됨 (어느 회사 주식 · 부동산 · 영업권 · 사업권 등 이름이 있음). 자산을 사며 생긴 매매대금을 상계·대용납입하는 것도 여기 | 현물 |
| 현금 납입 + 위 둘 중 하나가 같은 공시에 | 섞임 |
| 신호는 걸렸으나 확인해 보니 현금만 | 현금 |
| 현금이 아닌 건 분명한데 빚도 자산도 특정되지 않음 | 불명 |

"특정됐다"의 기준 — 빚: 빚의 종류와, 금액 · 차입 시점 · 채권자 중 하나 이상이 적혀 있다. 자산: 자산의 이름이 적혀 있다.

# 헷갈리기 쉬운 것

- 자금 용도의 "채무상환자금"은 받은 돈을 어디에 쓰는지이지 납입 방식이 아니다.
- "청약증거금은 납입금으로 대체/상계" 같은 절차 문장은 납입 방식 근거가 아니다.
- 자산을 사며 같은 날 생긴 매매대금을 상계·대용납입하면 현물이다 (빚이 아니다).
- "현물출자 여부" 칸 값은 참고만 한다. 글 · 대상자 표와 다르면 글 · 대상자 표가 우선이다.
- 빚이나 받는 자산이 글에 특정돼 있지 않으면 추측하지 말고 불명. 정황으로 짐작해 값을 고르지 않는다.

# 출력

JSON 하나만 낸다.

```json
{"payment_type": "...", "evidence": ["입력 원문 문장 그대로", "..."], "asset": "받는 자산 이름 | null", "debt": "빚 종류 | null", "reason": "한 문장"}
```

- payment_type은 현금 / 빚→주식 / 현물 / 섞임 / 불명 중 하나.
- evidence는 입력 안의 문장을 잘라서 그대로 1~3개 (요약 · 번역 금지). [대괄호 제목]과 "칸 이름:"은 넣지 않는다.
- 현물이면 asset 필수, 빚→주식이면 debt 필수, 섞임이면 해당하는 쪽 필수. 없으면 불명으로 바꾼다.

# 예시 (가상의 회사 · 숫자)

예시 1 — 입력 중:
[받는 사람] PART: 가나캐피탈 / MNTH: 2025.03.02 단기차입금 30억원 차입
[글] 대상자가 회사에 대하여 보유한 단기차입금 채권 30억원을 출자전환하여 납입한다.
출력: {"payment_type": "빚→주식", "evidence": ["대상자가 회사에 대하여 보유한 단기차입금 채권 30억원을 출자전환하여 납입한다."], "asset": null, "debt": "단기차입금", "reason": "회사가 원래 진 단기차입금(금액 · 시점 특정)을 주식으로 바꾼다."}

예시 2 — 입력 중:
[납입 자산] PIN_EXT_YN: 예 / PIN_VAL: 12,000,000,000
[글] 대상자가 보유한 주식회사 다라소재 보통주 400,000주를 현물출자 방식으로 납입한다.
출력: {"payment_type": "현물", "evidence": ["대상자가 보유한 주식회사 다라소재 보통주 400,000주를 현물출자 방식으로 납입한다."], "asset": "주식회사 다라소재 보통주", "debt": null, "reason": "받는 자산(다라소재 주식)이 이름으로 특정된다."}

예시 3 — 입력 중:
[받는 사람] PART: 마바투자조합 (현금 납입) / PART: 사아은행 (출자전환)
[글] 마바투자조합은 현금으로 납입하고, 사아은행은 회사에 대한 대출금 채권 50억원을 출자전환한다.
출력: {"payment_type": "섞임", "evidence": ["마바투자조합은 현금으로 납입하고, 사아은행은 회사에 대한 대출금 채권 50억원을 출자전환한다."], "asset": null, "debt": "대출금", "reason": "현금 납입과 특정된 빚의 출자전환이 함께 있다."}

예시 4 — 입력 중:
[돈의 용도] FND_USE_RD(채무상환자금): 3,000,000,000
[글] 조달 자금은 금융기관 차입금 채무상환에 사용할 예정이다.
출력: {"payment_type": "현금", "evidence": ["조달 자금은 금융기관 차입금 채무상환에 사용할 예정이다."], "asset": null, "debt": null, "reason": "채무상환은 받은 현금의 용도이고 납입은 현금이다."}

예시 5 — 입력 중:
[글] 본 신주는 대상자와 체결한 주식매매계약에 따른 매매대금과 상계하는 방식으로 납입한다.
출력: {"payment_type": "불명", "evidence": ["본 신주는 대상자와 체결한 주식매매계약에 따른 매매대금과 상계하는 방식으로 납입한다."], "asset": null, "debt": null, "reason": "현금이 아닌 건 분명하나 어느 회사 주식인지 특정되지 않는다."}
