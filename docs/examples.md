# 실제 예시 — agent 질문과 답 · 사실 카드 · 알림

모두 실제 실행 결과를 그대로 옮겼습니다 (손으로 고친 글 없음). agent 답은 프롬프트 v9 · Claude Sonnet 5.5 · 기준일 2026-10-19 실행
`main2-v9-20261024`에서, 6개 모두 채점 통과한 답입니다. 전체 질문과 답은 [eval/answers_train_v9.md](eval/answers_train_v9.md) · [eval/answers_sealed_v9.md](eval/answers_sealed_v9.md).

## 1. agent 질문과 답 6개

### ① 회사 전체 희석 — "뉴온 주식 얼마나 늘어날 수 있어?"
도구: `get_company_dilution(company='뉴온')` · 2 turns · $0.015 · 4.3초
```
뉴온 진행 중인 CB 2건을 합치면 회사 합산 최대 희석률은 14.6%입니다. 리픽싱 바닥가까지 전환가가 내려가는 최악의 경우 회사 합산 최악 희석률은 18.2%입니다. 기존 주식 37,154,307주에 새로 늘 수 있는 주식은 6,343,281주 기준입니다.

근거: 접수번호 20250115000342, 20250115000341
```

### ② 비교 — "뉴온 CB 큰 편이야?"
도구: `get_company_dilution(company='뉴온')` → `compare_event(rcept_no='20250115000342')` · 3 turns · $0.026 · 5.5초
```
뉴온 CB(2025-01-15 공시)의 예전 사채 잔량 포함 희석률은 12.0%입니다. 코스닥 CB 1,163건 중 35백분위로, 중앙값(15.8%)보다 작은 편이에요.

근거: 접수번호 20250115000342
```
"큰 편 · 작은 편"은 백분위로만 말하고, 기준이 다른 희석률(이번 공시만 7.9% · 잔량 포함 12.0%)을 섞지 않습니다.

### ③ 조항 원문 인용 (RAG) — "대창솔루션 2023년 10월 전환사채의 시가하락에 따른 전환가격 조정 주기는?"
도구: `search_events(company='대창솔루션', type='CB', date_from='2023-10-01', date_to='2023-10-31')` → `search_filing_text(rcept_no='20231013000400', topic='리픽싱', question=…)` · 3 turns · $0.015 · 6.0초
```
대창솔루션 2023년 10월 전환사채는 발행일로부터 7개월이 되는 날 이후 매 7개월마다 전환가격을 조정합니다.

- 인용 1: "본 사채의 발행일로부터 7개월이 되는 날 및 이후 만기일 전월까지 매 7개월이 경과한 날을 전환가격 조정일로 하고"
- 인용 2: "본 사채 발행일로부터 매 7개월이 되는 날을 전환가격 조정일로 하고"

근거: 접수번호 20231013000400
```
채점기는 따옴표 안 글이 도구가 돌려준 원문 조각에 실제로 있는지, 정답 문구와 얼마나 겹치는지를 봅니다.

### ④ 함정 — 공시에 없는 조항: "지투지바이오 2026년 3월 전환사채 매도청구권(Call Option) 조건은?"
도구: `search_events(…)` → `search_filing_text(rcept_no='20260316000004', topic='콜', …)` · 3 turns · $0.020 · 9.9초
```
이 공시에 매도청구권(Call Option) 조항은 없어요. 원문에 콜 조항이 적혀 있지 않습니다.

근거: 접수번호 20260316000004
```
이 공시에는 풋(조기상환청구권) 조항만 있습니다. 비슷한 풋 조항으로 대신 답하지 않습니다 (함정 10문제 · 봉인 6문제에서 지어낸 답 0).

### ⑤ 특수 상황 문장 — "DH오토넥스 희석 얼마나 돼?"
도구: `get_company_dilution(company='DH오토넥스')` · 2 turns · $0.009 · 5.7초
```
회생 절차 중인 회사의 발행이에요. DH오토넥스에서 진행 중인 공시는 CB 1건(2024-09-19 접수)이고, 회사 합산 최대 희석률은 27.1%, 회사 합산 최악 희석률도 27.1%입니다. 전환가 500원에 신주 29,400,000주가 늘어나는 구조이고, 조달액은 147억입니다. 리픽싱 없어요.
공시 당시 거래정지 상태였습니다.

근거: 접수번호 20240913000851
```
"회생 절차 중인 회사의 발행이에요." · "리픽싱 없어요"는 사실 카드의 표시(flag)에 따라 붙는 정해진 문장입니다. 거래정지는 공시 당시 신호라 "현재"라고 하지 않습니다.

### ⑥ 되묻기 — "삼성 희석 얼마야?"
도구: `get_company_dilution(company='삼성')` → 결과 ambiguous · 2 turns · $0.006 · 3.3초
```
"삼성"으로 찾으면 회사가 여러 곳 나와서 어느 회사인지 정하지 못했어요. 어느 회사를 말씀하시는 건가요?

- 삼성제약
- 삼성에스디에스
- 삼성바이오로직스
- 삼성FN리츠
- 삼성SDI

회사를 알려 주시면 희석률을 확인해 드릴게요.
```
도구로 답할 수 없는 질문("뉴온 목표 주가 얼마야?")에는 도구를 부르지 않고 "이 도구로는 답할 수 없어요. 공시 기반 희석 정보만 드릴 수 있어요."라고 답합니다.

## 2. 사실 카드 — 뉴온 CB (20250115000342)

(`values`는 원문에서 뽑은 값, `calc`는 계산, `signals`는 켜진 신호, `flags`는 특수 상황 표시).

## 3. 알림 — 같은 카드로 만든 문단 5개

위 카드를 Claude Sonnet 5.5에 넣어 만든 알림입니다 (알림 50건 점검 실행 결과 중 1건, 숫자는 모두 카드 값).
개인 인수자 이름만 "김○○"으로 가렸습니다.

```
📊 얼마나 큰가
50억 CB예요. 전환가 1,560원으로 3,205,128주(7.9%)가 새로 생길 수 있어요. 주가가 내리면 전환가가 1,092원(70.0%)까지 내려가 최대 11.0%까지 커져요. 아직 남아 있는 예전 사채 1,856,102주까지 합치면 12.0%예요. 이자는 표면 6%, 만기 6%예요.

💰 왜 조달하나
채무상환 50억(100%)이에요. 50억 전부 빚을 갚는 데 써요.

👤 누가 사나
사모예요. 김○○이 50억 전액을 사요.

📅 언제 풀리나
발행일은 2025-01-16이고, 2026-01-16부터 2027-12-16까지 주식으로 바꿀 수 있어요. 전환 시작일이 발행일로부터 1년 뒤라 사모 1년 잠금이에요. 만기는 2028-01-16이에요.

🔍 이 회사 괜찮나
주의할 점 3가지예요.
⚠️ 현금은 들어오지 않아요. 빚 50억을 주식(CB)으로 바꿔요. "[빚: (주)뉴온 제13회 무기명식 이권부 무보증 사모 전환사채] 본건 전환사채는 전환사채인수인이 기보유한 전환사채와 상계하여 발행하는 차환발행으로, 전환사채인수인은 전환사채 인수대금에 해당하는 (주)뉴온 제13회 무기명식 이권부 무보증 사모 전환사채(권면금액 \5,000,000,000원)를 납입기일에 발행회사에게 대용납입 하기로 하며, 발행회사는 전자등록되어 있는 (주)뉴온 제13회 무기명식 이권부 무보증 사모 전환사채를 상환 및 말소 처리한다."
⚠️ 모은 돈 50억 중 50억(100%)을 빚 갚는 데 써요.
⚠️ 최근 2년 6번째 조달이에요 (유상증자 4 · CB 2).

📎 근거: 접수번호 20250115000342
```
