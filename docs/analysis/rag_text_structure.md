## 4. 어느 부분을 RAG로 — 기준과 결정

**기준 (셋 다 맞아야 RAG 대상)**
- (a) **값 칸에 없다** — 칸에 있으면 사실 카드로 답한다. RAG가 대신하면 같은 질문에 답이 두 군데서 나와 어긋날 수 있다.
- (b) **공시마다 다르다** — 같은 글이면 "이 회사는?"의 답이 아니다. 검색에서 진짜 답을 밀어낸다.
- (c) **투자자 판단에 쓰인다** — 장소·서류 같은 절차 정보는 판단에 안 쓰인다.

|---|---|---|---|---|---|---|---|

## 5. 아직 확인 못 한 것 (전체 2,978건 글을 받으면)
- 방식별로 대표 1건만 펼쳐 봤다. 같은 방식 안에서 모양이 크게 다른 회사(외국 법인, 회생, 우선주)를 5건씩 더 펼쳐 볼 것.
- 주제는 미리 정한 단어로 셌다. 단어 없이 표 밖 글의 번호 제목을 전부 뽑아 빠진 주제가 없는지 확인할 것.
- 일부 칸은 원문 자체에 숫자가 빠져 있다(예: "산정한개월 가중산술평균주가"). 답 문장 검사 때 감안.
