# 3번 검증 보고 — 사실 카드 · 희석률 · 신호 (2026-10-22)

## 1. 무엇을 검증했나

DB 값(⑨에서 99.9% 확인)을 읽어 **희석률을 계산하고 신호를 켜는 층**이 맞는지.
식 자체가 아니라 "어떤 공시를 계산에 넣고, 어떤 상황에서 식을 쓰면 안 되는지"를 봤다.

## 2. 어떻게 했나 (3단계)

| 단계 | 한 일 | 누가 |
|---|---|---|
| 1. 정의 | 희석률이 틀릴 수 있는 상황 10개를 적고 처리 방법을 정함 (`calc_criteria.md`) | 사용자 + Claude |
| 2. 세기 | 2,978건 전부에 그 상황이 몇 건 있고 얼마나 틀리는지 세기만 함. 코드 안 고침 | Claude Code |
| 3. 고치기·확인 | 많이 틀리는 것만 고침 → 956개 회사 합산을 **정의서만 보고 따로 짠 계산기**로 전수 재계산해 대조 | Claude Code 고침 / Claude 대조 |

⑨와 다른 점: 정답표 240건을 손으로 만들지 않았다. 산수는 결정적이라 손 계산 10건이 맞으면 전부 맞는다. 대신 "어떤 상황이 실제로 몇 건인지"를 전수로 세고, 독립 재구현으로 전수 대조했다.
